# lew

Un espace de travail pour piloter ses projets avec des agents de développement, sur desktop et mobile.

lew relie projets, conversations, branches Git, exécutions et pull requests pour reprendre un travail avec le bon contexte.

## Parcours cible

Lancer une modification sur un projet, passer sur un autre, fermer son ordinateur puis retrouver la tâche, sa branche et sa PR depuis son téléphone.

## Direction

- Interface inspirée de macOS, conçue principalement pour desktop et adaptée au mobile.
- Espaces de travail isolés avec Git worktrees.
- Intégration Codex App Server à valider par un premier prototype technique.
- Exécution persistante côté serveur, indépendante du navigateur.
- Intégration GitHub pour les repos, branches, issues, PR et CI.

## État

Planification initiale. Aucune application ni intégration opérationnelle pour le moment.
