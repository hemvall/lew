# Repository instructions

Use short, descriptive English branch names: feat/<change>, fix/<problem>, refactor/<component>, or chore/<maintenance>. Never use codex/ prefixes, arbitrary dates, baseline names, or v2 suffixes. Name the actual behavior or component, for example feat/mission-orchestration-langgraph or fix/mission-resume.

Commit messages use feat:, fix:, refactor:, docs:, test:, or chore: without parenthesized scopes. Write pull request titles and descriptions in English.
